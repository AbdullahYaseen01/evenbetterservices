# EvenBetterServices

Marketing site for EvenBetterServices, an AI, automation, and software studio.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Enquiry delivery is off until `ENQUIRY_WEBHOOK_URL` or the Resend variables in `.env.example` are set. The form does not report success unless a real delivery responds successfully. See `HANDOVER.md`.
